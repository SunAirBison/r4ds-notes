Question 1

NoteNote

The Problem

Use what you’ve learned to improve the visualization of the departure times of cancelled vs. non-cancelled flights.

The Solution

We can use a boxplot instead of a frequency chart for improved visualization.

# Tibble from example in previous section (10.4)
flights13 <- nycflights13::flights |> 
  mutate(
    cancelled = is.na(dep_time),
    sched_hour = sched_dep_time %/% 100,
    sched_min = sched_dep_time %% 100,
    sched_dep_time = sched_hour + (sched_min / 60)
  ) 

flights13 |> ggplot() +
    geom_boxplot(aes(y = sched_dep_time, x = cancelled))

Question 2

NoteNote

The Problem

Based on EDA, what variable in the diamonds dataset appears to be most important for predicting the price of a diamond? How is that variable correlated with cut? Why does the combination of those two relationship lead to lower quality diamonds being more expensive?

The Solution

First I looked at scatterplots of all the pairs of variables. The categorical variables (cut for example) did not give any useful information without jittering.

# Scatterplots for continous variables
pairs(price ~ carat + depth + table, data = diamonds)

From the above plots, there seems to be little to no change in price with a change in depth or table while there is an exponential relationship with price and carat.

diamonds |> ggplot(aes(x = cut, y = price)) + geom_jitter()
diamonds |> ggplot(aes(x = color, y = price)) + geom_jitter()
diamonds |> ggplot(aes(x = clarity, y = price)) + geom_jitter()

From the scatterplots of the discrete variables, cut does not show a relationship other than the number of observations increase with cut quality. Color simillarly does not show a relationship with price. Clarity however seems to have some points that increase with clarity and another set of points that increase up to VS1 then start to decrease. From this, the variable that seems to be the most important is carat.

Next lets compare carat and cut.

diamonds |> ggplot(aes(x = cut, y = carat)) + geom_boxplot()

Looking at the boxplot above, fair has the 3 largest outliers in carat in the whole data set. These extreme values are causing the mean carat of the fine cut quality category to be higher than expected. Thus when we look at plot between price and cut, fair cut diamonds will tend to have a higher mean price compared to the other cut qualties.

Question 4

NoteNote

The Problem

One problem with boxplots is that they were developed in an era of much smaller datasets and tend to display a prohibitively large number of “outlying values”. One approach to remedy this problem is the letter value plot. Install the lvplot package, and try using geom_lv() to display the distribution of price vs. cut. What do you learn? How do you interpret the plots?

The Solution

diamonds |> ggplot(aes(x = cut, y = price)) + lvplot::geom_lv()

From this plot it is easier to see the skew of each of the plot and how heavy the tails of each cut is. We can see that since the boxes of fair are less wide at higher prices compared to the other cut qualities that there are less observations in those areas.

Question 5

NoteNote

The Problem

Create a visualization of diamond prices vs. a categorical variable from the diamonds dataset using geom_violin(), then a faceted geom_histogram(), then a colored geom_freqpoly(), and then a colored geom_density(). Compare and contrast the four plots. What are the pros and cons of each method of visualizing the distribution of a numerical variable based on the levels of a categorical variable?

The Solution

# Base plot
p <- diamonds |> ggplot(aes(x = price))

p + geom_violin(aes(y = cut))
p + geom_histogram(bins = 50) + facet_wrap(~ cut)
p + geom_freqpoly(aes(color = cut))
`stat_bin()` using `bins = 30`. Pick better value `binwidth`.
p + geom_density(aes(color = cut))

The violin plot is good at showing the changes in proportion of each of the levels in the area with the majority of the data points, but this plot does a poor job with showing small changes in the tail of each of the levels.

With the histogram it is easy to see and compare the number of observation in each price bin; however it is hard to compare between factor levels since the number of obserations in each level may be vastly different.

The frequency polynomial plot does good job at showing how the number of observations changes as price increases. This plot however has an issue with showing the amount of values in the peaks. It is hard to determine if there is a large range where most observations are found or that a single price has many observation.

The density plot is good at showing modality and where most of hte observations are, but simillarly to the violin plot it is difficult to see individual observations and smaller changes.

Question 6

NoteNote

The Problem

If you have a small dataset, it’s sometimes useful to use geom_jitter() to avoid overplotting to more easily see the relationship between a continuous and categorical variable. The ggbeeswarm package provides a number of methods similar to geom_jitter(). List them and briefly describe what each one does.

The Solution

From the ggbeeswarm [github page][https://github.com/eclarke/ggbeeswarm], it includes 2 methods: geom_quasirandom and geom_beeswarm. The github page describes geom_quasirandom as “Uses a van der Corput sequence or Tukey texturing (Tukey and Tukey “Strips displaying empirical distributions: I. textured dot strips”) to space the dots to avoid overplotting. This uses sherrillmix/vipor.” geom_beeswarm uses another library, beeswarm, to do point-based offset.

The Problem

How could you rescale the count dataset above to more clearly show the distribution of cut within color, or color within cut?

The Solution

To more clearly show the distribution of cut / color pairs, we can use proportions instead of counts.

diamonds |> 
  count(color, cut) |> 
  mutate(proportion = n / sum(n)) |>  
  ggplot(aes(x = color, y = cut)) +
  geom_tile(aes(fill = proportion))

Use geom_tile() together with dplyr to explore how average flight departure delays vary by destination and month of year. What makes the plot difficult to read? How could you improve it?

10.5.3 Two numerical Variables

Question 1

NoteNote

The Problem

Instead of summarizing the conditional distribution with a boxplot, you could use a frequency polygon. What do you need to consider when using cut_width() vs cut_number()? How does that impact a visualization of the 2d distribution of carat and price?

The Solution

When using cut_width(), you need to consider what bin lengths while in cut_number() you need to consider the number of bins. Depending on the number of bins or the bin width, the chart may not provide very much information or becomes difficult to interpret due to visual clutter.

Question 2

NoteNote

The Problem

Visualize the distribution of carat, partitioned by price.

The Solution

# Dataset used in this section
smaller <- diamonds |> 
  filter(carat < 3)

# Plot using cut_number
smaller |>
  ggplot(aes(x = carat)) +
  geom_freqpoly(
    aes(
      group = cut_number(price, 10), 
      color = cut_number(price, 10)
      )
    )
`stat_bin()` using `bins = 30`. Pick better value `binwidth`.
# Plot using cut_width
smaller |>
  ggplot(aes(x = carat)) +
  geom_freqpoly(
    aes(
      group = cut_width(price, 1000), 
      color = cut_width(price, 1000)
      ),
      bins = 30
    )

The Problem

How does the price distribution of very large diamonds compare to small diamonds? Is it as you expect, or does it surprise you?

The Solution

diamonds |> 
  ggplot() +
  geom_boxplot(
    aes(
      x = table,
      y = price,

      ),
      orientation = "x"
    )

Using table as data representing the size of the diamond, the price of diamonds increase as table increase until around 60, where it slightly decreases. This is somewhat surprising, but there are likely factors other than size (like clarity) that have an effect on price.

Question 5

NoteNote

The Problem

Two dimensional plots reveal outliers that are not visible in one dimensional plots. For example, some points in the following plot have an unusual combination of x and y values, which makes the points outliers even though their x and y values appear normal when examined separately. Why is a scatterplot a better display than a binned plot for this case?

diamonds |> 
  filter(x >= 4) |> 
  ggplot(aes(x = x, y = y)) +
  geom_point() +
  coord_cartesian(xlim = c(4, 11), ylim = c(4, 11))

The Solution

A scatterplot is able to display ususal pairs, while a binned plot is unable to since it is a 1D plot. Most outliers in the plot would fit into a bin with many observations that are not outliers.

Question 6

NoteNote

The Problem

Instead of creating boxes of equal width with cut_width(), we could create boxes that contain roughly equal number of points with cut_number(). What are the advantages and disadvantages of this approach?

ggplot(smaller, aes(x = carat, y = price)) + 
  geom_boxplot(aes(group = cut_number(carat, 20)), orientation = "x")

The Solution

Using cut_number() is faster than using cut_width(), since each dataset will have a differing scale, which requires you to first determine what lengths are appropriate. cut_number() will do the calculations for you.The main disadvantage is that the bins are harder to compare to one another, since with differing lengths inferences done on them are worse compared to even sized bins.
