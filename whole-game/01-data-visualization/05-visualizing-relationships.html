Question 2

NoteNote

The Problem

Make a scatterplot of hwy vs. displ using the mpg data frame. Next, map a third, numerical variable to color, then size, then both color and size, then shape. How do these aesthetics behave differently for categorical vs. numerical variables?

The Solution

mpg |> 
    ggplot(aes(x = displ, y = hwy)) +
    geom_point()
mpg |> 
    ggplot(aes(x = displ, y = hwy, color = cty)) +
    geom_point()
mpg |> 
    ggplot(aes(x = displ, y = hwy, size = displ)) + 
    geom_point()
mpg |> 
    ggplot(aes(x = displ, y = hwy, color = cty, size = displ)) +
    geom_point()
# Raises error due to passing a continous variable to shape
mpg |> 
    ggplot(aes(x = displ, y = hwy, shape = cty)) + 
    geom_point()

When the variable is categorical, all three aesthetics behave simillarly. Each category is assigned a unique color/size/shape.

When the variable is numerical, each of the aesthetics does something different:

  • color maps each value on a gradient, keeping all information.
  • size rounds each value to be one of a set of sizes with a positive integer value. It loses some information from the variable.
  • shape is unable to map to a numerical (continous) variable and raises an error when we attempt to map it.

The Solution

Question 4

NoteNote

The Problem

What happens if you map the same variable to multiple aesthetics?

The Solution

mpg |> 
  ggplot() + 
  geom_point(aes(x = hwy, y = hwy, color = hwy))
  mpg |> 
  ggplot() + 
  geom_point(aes(x = hwy, y = hwy, color = hwy, size = hwy))

When we map the same variable to multiple aesthetics (in scatterplots), The values follow a diagonal line, since for each point x and y are equal. For color and size, they became gradients with one extreme on one side of the line to the other extreme on the other end.

Question 5

NoteNote

The Problem

Make a scatterplot of bill_depth_mm vs. bill_length_mm and color the points by species. What does adding coloring by species reveal about the relationship between these two variables? What about faceting by species.

The Solution

penguins |>
  ggplot(aes(color = species)) + 
  geom_point(
    aes(x = bill_length_mm, y = bill_depth_mm), 
    na.rm = TRUE)

This plot shows that the bill length and depth of the penguins measured are clustered by species.

penguins |>
  ggplot(aes(color = species)) + 
  geom_point(
    aes(x = bill_length_mm, y = bill_depth_mm), 
    na.rm = TRUE) +
  facet_wrap(~species)

When faceting by species, it is easier to see that Gentoo penguins have a noticible difference in bill depth to the other species and that Adelle penguins have a smaller bill length comapared to the other species.

Question 6

NoteNote

The Problem

Why does the following yield two separate legends? How would you fix it to combine the two legends?

ggplot(
  data = penguins,
  mapping = aes(
    x = bill_length_mm, y = bill_depth_mm, 
    color = species, shape = species
  )
) +
  geom_point() +
  labs(color = "Species")
Warning: Removed 2 rows containing missing values or values outside the scale range
(`geom_point()`).

The Solution

Two separate legends appear since our custom name for color is different that the default one for shape. We can fix it by either changing color back to the default legend name or change the name for shape to “Legend”.

ggplot(
  data = penguins,
  mapping = aes(
    x = bill_length_mm, y = bill_depth_mm, 
    color = species, shape = species 
  )
) +
  geom_point(na.rm = FALSE) +
  labs(color = "Species", shape = "Species")
Warning: Removed 2 rows containing missing values or values outside the scale range
(`geom_point()`).

Question 7

NoteNote

The Problem

Create the two following stacked bar plots. Which question can you answer with the first one? Which question can you answer with the second one?

ggplot(penguins, aes(x = island, fill = species)) +
  geom_bar(position = "fill")
ggplot(penguins, aes(x = species, fill = island)) +
  geom_bar(position = "fill")

The Solution

The first plot (species vs island) shows for each island the proportion of penguins on that particular island. This plot can tell us what the population of each island look like. The second plot (island vs species) shows for each penguin species, the proportion of that species on each island. This plot can tell us the proportion of the total population of each penguin species across the different islands.
